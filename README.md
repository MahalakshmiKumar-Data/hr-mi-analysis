# hr-mi-analysis
HR MI Dashboard — IBM Employee Dataset
Tools: Excel, Power BI, DAX, Power Query
Dataset: 1,470 employees across 3 departments
Key findings:

Sales has the highest attrition rate at 20.6% despite the highest average salary of £6,959/month
R&D has the lowest attrition at 13.8%
Overall attrition rate: 16.1%
Salary alone is not driving retention in the highest-paying department

Excel techniques: COUNTIFS, SUMIFS, AVERAGEIFS, PivotTables, Power Query
Power BI techniques: DAX measures, star schema data model, Date dimension, interactive slicers, published to Power BI Service
